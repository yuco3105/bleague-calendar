# Bカレ - Bリーグ全試合スケジュール（非公式）

Bリーグ（B.PREMIER）の「その日の全試合」がひと目でわかる非公式・個人利用のスケジュールアプリです。

## 機能

- 1日の全試合を一覧表示（日付タブで移動、試合数つき）
- 🔵 開幕前のプレシーズンゲームも「PRE」表示で同じ日付タブに掲載
- 🇯🇵 男子日本代表の試合日程タブ
- ⭐推しクラブを選ぶと各日の一番上に金色で固定表示
- 🎨きせかえ（背景テーマ4種＋好きな写真を背景に設定可能）
- 各クラブの公式Xアカウント・ニュースサイトへのリンク
- 試合カードをタップすると公式の試合詳細ページへ
- ホーム画面に追加すればアプリのように使えます（PWA）
- iPhoneウィジェット対応（Scriptableアプリに `widget-loader.js` を貼ると、以後は `widget-scriptable.js` の最新版を毎回読み込むので貼り直し不要）

## 仕組み

- `scrape-season.js` がBリーグ公式サイトの日程ページから試合データ（日付・対戦・会場・時刻という事実情報）を取得し `games.json` を生成
- GitHub Actions（`.github/workflows/update-data.yml`）が毎朝6時（JST）に自動更新
- `scrape-preseason.js` が開幕前のプレシーズンゲーム（リーグ公式に日程ページが無く、各クラブが個別発表するもの）を集約記事とそのカレンダーから取得し `preseason.json` を生成（`update-preseason.yml` が毎朝6:15 JST）
- `scrape-japan-results.js` が代表戦（W杯予選）の結果をFIBA公式から取得し `japan.json` を更新（`update-japan.yml` が毎朝6:30 JST）。強化試合はFIBA管轄外のため手動更新
- `index.html` がこれらのJSONを読み込んで表示
- ニュースは自前で保存・再配信せず、外部ニュースサイトの検索結果へリンクするのみ
